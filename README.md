## About
A full stack web application for a Baking Shop, allowing customers to navigate food products that are made by the seller. 

## Tech Stack

| Layer | Technology|
|---|---|
| **Backend** | Go |
| **Frontend** | HTML, CSS, JavaScript |
| **Database** | SQLite |
| **Hosting** | Self Hosted Ubuntu Server
| **Task Runner** | Makefile|

## Run 
```go
go run ./cmd
```
